## Workflow

1. Drop new files into `_inbox/`.
2. Preview their destinations with `_admin/sort_inbox.py`; add `--apply` to move matched files.
3. Create a topic with `_admin/new_topic.py <course-folder> <NN> <topic-name>`.
4. Fill Part 1 after the lecture, Part 2 after the exercise, and Part 3 during exam preparation.
